# Galactic Delivery Drones 🚀

Учебный Java-проект по объектно-ориентированному программированию (OOP).  
Реализует систему доставки грузов дронами между космическими объектами.

---

## 📌 Возможности

- Создание планет и космических станций  
- Создание лёгких и тяжёлых дронов  
- Создание груза и задач доставки  
- Назначение задачи дрону с проверками  
- Завершение задачи  
- Расчёт примерного времени доставки  

---

## 🧱 Используемые концепции

- Инкапсуляция  
- Наследование  
- Полиморфизм  
- Enum  
- Контроль состояний объектов
